# Publish LaptopScreenGuard

1. Extract this repository ZIP.
2. In your existing GitHub repository, open Settings > General, set Repository name to LaptopScreenGuard and confirm.
3. Upload extracted contents to the repository root. Keep the downloads ZIPs zipped.
4. Commit and check all four README downloads.
5. Review/remove obsolete files with the old app name from your repo.

Suggested description: Windows webcam privacy app with phone, shutter, lens-cover and registered-face editions, black overlay and temporary input blocking.
