LaptopScreenGuard - 03-Phone-Shutter-and-Cover

Branding update: LaptopScreenGuard logo for tray and application windows.
Detection and input handling are unchanged from the GitHub source.

NEW INSTALLATION
Install Python 3.12 x64, extract this ZIP and run Install-LaptopScreenGuard.cmd.
Internet is needed for initial packages and model download.

EXISTING INSTALLATION
Exit LaptopScreenGuard from the tray. Extract the edition you want to use.
Run Update-Existing-Installation.cmd under the same Windows account.
The previous program is backed up as LaptopScreenGuard.pyw.bak.
The updater installs this ZIP's edition; choose the matching edition to keep
your existing mode. Modes 1-3 share one installation folder. Run only one.

RECOVERY
Ctrl+Shift+F12 pauses/resumes monitoring. Ctrl+Alt+Delete opens Windows security.
Use Uninstall-LaptopScreenGuard.cmd only when you want to remove the app.

Validation: Python syntax, unchanged detection/input code and ZIP contents
checked. Actual Windows tray rendering and webcam require laptop testing.
