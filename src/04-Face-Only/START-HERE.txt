LaptopScreenGuard - Face Only with Live Enrollment Preview

EXISTING LAPTOP
1. Extract this ZIP fully.
2. Exit LaptopScreenGuard using its system tray menu.
3. Run Update-Existing-Installation.cmd under the same Windows account.
   Your old program is backed up as LaptopScreenGuard.pyw.bak.
   Existing owner-face.npz (enrollment and PIN) is preserved.
4. Right-click the tray icon > Enroll My Face or Replace Enrolled Face.
5. Watch the mirrored preview. A green box means a suitable face was found.
6. For replacement enter your existing PIN. For first enrollment choose and
   confirm a PIN of at least 6 digits. Click Capture & Enroll.
7. After the success message monitoring resumes. Test leaving and returning.

NEW LAPTOP
Install Python 3.12 x64 on Windows 10/11 x64.
Extract ZIP and run Install-LaptopScreenGuard.cmd.
Internet is needed for initial dependencies and model downloads.
Open the tray menu > Enroll My Face, then follow steps 5-7 above.

UI
- Live mirrored preview and face bounding box.
- Guidance for missing/multiple faces, distance, light and blur.
- Capture & Enroll and Cancel controls.
- Enrollment window temporarily suspends the overlay and input hooks.
- Cancel preserves the existing enrollment. Closing grants a two-second
  recognition grace period before ordinary monitoring resumes.
- Monitoring uses the existing camera capture thread, not a second webcam.
- No webcam photo files are saved. Local face embedding and salted PIN hash
  are saved only when Capture & Enroll succeeds.

RECOVERY
Ctrl+Shift+F12 pauses monitoring. Ctrl+Alt+Delete opens Windows security.
If an update fails, exit the app and restore LaptopScreenGuard.pyw.bak.
Uninstall-LaptopScreenGuard.cmd removes enrollment as well as the app.

VALIDATION
Python compilation and offscreen UI checks are performed where available.
Live Windows webcam, model matching, input hooks and startup must be tested
on your laptop. This is a preview release, not Windows Hello or account locking.
Face matching can accept photos/videos. Use Windows+L to lock your session.

Source base: isanjiiv/LaptopScreenGuard, src/04-Face-Only.
Original dependency/model terms continue to apply.
